# awatake ホームページ（第5版）

「80歳から、AIと向き合う毎日。」— awatake（1946年11月生まれ）の公式ホームページです。

第4版（`ホームページ４`）をベースに、80歳の節目に合わせて内容を刷新したものです。
第4版はそのまま残してあります。

## 内容

- **ストーリー** — 精密機器メーカーの技術者から中小企業コンサルタント、そしてAIプログラミングへ
- **プロフィール** — 経歴のタイムライン、図解プロフィール、講演動画
- **作品ギャラリー** — AIとの共同作業（バイブコーディング）でつくったゲーム・Webアプリ 9作品
- **AIショート動画** — プログラムで描いた音楽つきショートアニメ
- **活動** — 画像処理同好会、散歩・カラオケ
- **相談できること** — 企業経営・マーケティング・技術課題のコンサルティング
- **ブログ** — 健康・デジタル・コミュニティの記事、本館ブログ「カモシカのつぶやき」

## 年齢表記の方針（重要）

このサイトは**数年そのままでも通用する**ように、年齢を手作業で書き換えなくて済む設計にしています。

- **見出し・キャッチコピー**は「80歳**から**」という形にしてあります。81歳でも85歳でも文章として正しいままです。
- **実年齢の数字**（ヒーローのカウンター）は `js/script.js` が生年月日から自動計算します。誕生日を過ぎると自動的に1つ増えます。
- **コピーライトの年**も自動表示です。

生年月日を変える場合は `js/script.js` 冒頭の `BIRTH` を書き換えてください。

```js
var BIRTH = { year: 1946, month: 11, day: 1 };
```

年齢を自動表示したい箇所には、HTML側で属性を付けるだけです。

| 属性 | 表示されるもの |
|---|---|
| `data-age` | 現在の満年齢（例: 80） |
| `data-current-year` | 現在の西暦（例: 2026） |
| `data-count-age`（`.stat-num` に付与） | カウントアップ演出つきの満年齢 |
